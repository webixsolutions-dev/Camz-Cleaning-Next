# Booking UI Refinement v3

No new Supabase migration is required for this UI update.

## Updated
- Reworked the booking hero to a high-contrast light layout so content remains readable around the site navigation.
- Restyled desktop Services/Areas dropdowns to be smaller, rounded and less intrusive.
- Added a closable desktop-side pricing notice explaining that each service has its own package and optional add-ons are charged separately only when selected.
- Added the same pricing note inline on tablet/mobile.
- Reduced the service-card area to a centered `max-w-5xl` layout and made cards more compact.
- Refined the booking modal with a labeled 4-step progress header, close button, cleaner contact/property inputs and improved spacing.
- Added an in-form package/add-on explanation before service customization.
- Retained live pricing, GST display, add-on rules, custom quote/review flows and the booking status compatibility fix.
